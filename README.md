# 🌿 پلتفرم جامع رزرو اقامتگاه و بوم‌گردی «سرپناه» (Sarpanah)

> **مخزن یکپارچه (Monorepo): فرانت‌اند Next.js + بک‌اند FastAPI + مدل داده و ERD + راهنمای کامل راه‌اندازی**

سامانه مدرن و پایدار رزرواسیون آنلاین اقامتگاه‌های بوم‌گردی، ویلاهای ساحلی و کلبه‌های کوهستانی ایران با ویژگی‌های پیشرفته:
- 🎨 رنگ‌آمیزی زنده و خودکار صفحات بر اساس موقعیت جغرافیایی و اقلیم هر منطقه (مازندران ساحلی، گیلان جنگلی، اصفهان تاریخی، شیراز بهاری و کویر مرنجاب)
- 📅 تقویم تعاملی کاملاً شمسی ماهانه برای انتخاب بدون دردسر روزهای ورود و خروج مسافر
- 👥 سیستم برنامه‌ریزی هوشمند، همسفری و محاسبه خودکار سهم هزینه سفر گروهی
- ❤️ صفحه و قابلیت نشان‌گذاری اقامتگاه‌های برگزیده (علاقه‌مندی‌ها / Wishlist)
- 👤 پنل کاربری مسافر و میزبان همراه با قابلیت ویرایش مشخصات و بارگذاری عکس اختصاصی پروفایل
- 🗄️ معماری جامع پایگاه‌داده رابطه‌ای ۲۱ موجودیتی با دیاگرام اختصاصی ERD

---

## 📁 ساختار کامل پروژه (Project Architecture)

```
sarpanah/
├── frontend/               # رابط کاربری کلاینت (Next.js 14, Tailwind CSS, TypeScript)
│   ├── src/
│   │   ├── app/            # مسیرها و صفحات (خانه، اقامتگاه‌ها، جزئیات [id]، علاقه‌مندی‌ها، ورود، ثبت‌نام)
│   │   ├── components/     # کامپوننت‌های نوبار، تقویم شمسی ماهانه، کارت‌های سه‌بعدی، سفر گروهی
│   │   ├── hooks/          # هوک استخراج و اعمال تم‌های رنگی اقلیم
│   │   └── lib/            # کلاینت API، داده‌های مدل، ابزارهای کمکی
│   ├── public/             # تصاویر، فونت‌های وزیر و آیکون‌ها
│   ├── package.json        # تنظیمات و وابستگی‌های فرانت‌اند
│   └── tailwind.config.js  # استایل‌های مدرن و 3D Claymorphism
│
├── backend/                # سرویس سمت سرور (FastAPI, SQLAlchemy, Pydantic, Alembic)
│   ├── app/
│   │   ├── api/v1/         # مسیرهای API (اقامتگاه‌ها، رزروها، نظرات، کاربران، احراز هویت JWT)
│   │   ├── core/           # تنظیمات امنیت، هش پسورد، پیکربندی CORS و دیتابیس
│   │   ├── db/             # نشست پایگاه‌داده و اتصالات
│   │   ├── models/         # مدل‌های ۲۱ جدول پایگاه‌داده
│   │   ├── schemas/        # اسکیماهای اعتبارسنجی ورودی و خروجی
│   │   └── services/       # سرویس‌های تجاری و محاسباتی
│   ├── alembic/            # تاریخچه مایگریشن‌های پایگاه‌داده
│   ├── scripts/            # اسکریپت‌های اولیه بارگذاری داده‌ها (Seed Data)
│   ├── tests/              # آزمون‌های خودکار Pytest
│   ├── requirements.txt    # کتابخانه‌های پایتون
│   └── Dockerfile          # فایل داکر برای استقرار کانتینری
│
├── database_erd/           # نمودار موجودیت-ارتباط (ERD) و پایگاه‌داده
│   ├── accommodation-erd-maedeh.html   # دیاگرام گرافیکی و تعاملی ۲۱ جدول سیستم
│   └── accommodation-erd-maedeh.zip    # مستندات تکمیلی طراحی پایگاه‌داده
│
└── docs/                   # مستندات معماری، راهنماهای دیپلوی و API
```

## 🚀 راهنمای سریع راه‌اندازی (Quick Start Guide)

### ۱. اجرای فرانت‌اند (Frontend)

```bash
cd frontend
npm install
npm run dev
```
سامانه در مرورگر روی آدرس **`http://localhost:3000`** آماده مشاهده خواهد بود.

---

### ۲. اجرای بک‌اند (Backend)

```bash
cd backend
python -m venv .venv

# فعال‌سازی در ویندوز:
.venv\Scripts\activate
# فعال‌سازی در لینوکس / مک:
source .venv/bin/activate

pip install -r requirements.txt

# اعمال مایگریشن‌ها و ساخت جداول دیتابیس:
alembic upgrade head

# اجرای سرور بک‌اند:
uvicorn app.main:app --reload --port 8000
```
داکیومنت تعاملی Swagger API در آدرس **`http://127.0.0.1:8000/docs`** در دسترس است.
